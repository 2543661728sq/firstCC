# AI 视频数字礼官素材目录

请将生成好的礼官视频放在这个目录，文件名保持一致：

- `guardian_idle.mp4`
- `guardian_welcome.mp4`
- `guardian_gongshou_demo.mp4`
- `guardian_receive_tea_demo.mp4`
- `guardian_smell_tea_demo.mp4`
- `guardian_listening.mp4`
- `guardian_success_reply.mp4`
- `guardian_hint.mp4`
- `guardian_farewell.mp4`

Web 原型会按当前茶礼步骤和识别状态自动切换这些视频。视频未放入时，系统会自动使用茶席意向图作为兜底画面。
