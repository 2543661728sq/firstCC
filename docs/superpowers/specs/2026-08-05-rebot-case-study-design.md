# reBot Case Study Redesign

## Objective

将 reBot 从“系统截图展示”升级为面向产品/UIUX 岗位评审的交互设计案例。页面首先回答设计问题与设计判断，再用真实受试者、运行系统和操作视频构成可信的证据链。

## Audience

- 主要：产品设计、交互设计、UIUX 岗位评审。
- 次要：具身智能与人机交互研究方向评审。

## Narrative

1. 传统学习断点：静态图纸、名称记忆与孤立判断，难以连接结构、运动和任务目标。
2. 设计策略：以身体参与建立机械臂结构认知，形成“观察、定位、反馈、完成、记录”的具身学习闭环。
3. 方式对照：传统方式与 reBot 在输入、学习对象、反馈和证据沉淀上的差异。
4. 真实验证：用现场实验照片短片呈现受试者真实操作，再衔接系统中的手势输入、3D 场景与 AI 反馈。
5. 系统证据：已有两段精剪视频和完整界面图作为对设计策略的支撑。
6. 创新价值：具身交互、可理解反馈、可研究记录三项收束。

## Page Modules

### 1. Hero

保留现有 reBot 标题与真实系统界面图。首屏文案简化为项目定位与核心交互方式，不承担完整论述。

### 2. Learning Gap

新增全宽视觉图解：左侧是传统学习的三个断点，右侧是 reBot 的三项设计回应。图解以低饱和蓝灰作为基础，红色仅标识问题，浅绿色仅标识设计改善。

### 3. Embodied Learning Loop

新增五步闭环图：观察 3D 结构、参与式定位、获得语义反馈、完成任务、沉淀实验记录。每步使用简短标签、线性路径和一个可辨识图标，避免大段说明。

### 4. Traditional vs reBot

新增四行对照表，覆盖输入方式、理解对象、反馈、结果记录。传统方式保持低对比灰色，reBot 使用浅蓝和浅绿强调。

### 5. Field Evidence

新增“真实实验现场”模块。使用 5 张 JPG 现场照片制作 7-8 秒横向 MP4：照片以轻微错位的纸片形式从上方落入，按真实实验过程叠放，最终露出“受试者操作 / 手势参与 / 系统反馈”三项标签。视频无人物识别标注、无虚构数据、无背景音乐。

### 6. System Proof

保留现有 14 秒系统学习舞台视频和 13 秒实物机械臂操作视频，作为设计策略被真实执行的证明。视频继续使用完整画面优先的宽幅比例。

### 7. Interface Evidence

保留完整展示的系统界面图，改为与闭环五步图关联的证据卡，不使用裁切后的后台截图。

### 8. Innovation Value

以三张简洁价值卡收束：身体动作成为输入、AI 将结果转写为学习反馈、任务过程可供研究复盘。

## Visual Direction

- 延续现有浅色科技感：白色与浅蓝为背景，网格只作为轻量空间辅助。
- 主文字为深蓝灰，禁止低对比浅灰正文。
- 强调色用量控制在小面积：红色用于问题，绿色用于“完成/改善”，蓝色用于系统结构。
- 图解使用网页原生矢量化结构；若出现需要独立图标或图形资产的空缺，使用 Figma Agent 制作，并保持同一视觉系统。
- 页面响应式：在移动端将对照和闭环改为单列序列，照片短片保持 16:10 显示并不裁掉人物与屏幕。

## Constraints

- 不修改独立的 reBot 实验系统。
- 保留现有原始素材；新增视频输出到 `docs/images/case-rebot/video-exports/`。
- 不虚构研究数据、用户数量或实验结果。
- 现场图片由用户提供并授权用于个人作品集。

## Verification

- 页面在桌面和 390px 移动宽度无横向溢出。
- 所有文字与图解保持可读对比度。
- 现场短片能够加载、播放且首帧为可用封面。
- 新旧系统视频、照片短片与图片资源均返回成功状态。
- 原有独立实验系统目录保持不变。
