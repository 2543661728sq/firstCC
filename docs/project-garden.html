景观设计 · 庭院体验

花园景观设计

以日常休憩、观赏和社交为核心的庭院景观方案。页面将单张效果图转化为轻案例，重点表达空间分区、植物层次、路径组织和氛围营造。

庭院空间 植物配置 动线组织 生态舒适

Challenge

庭院需要同时满足观赏、休憩和日常活动，避免只停留在装饰性绿化。

Role

完成空间布局、植物层次配置、动线组织和整体效果表达。

Decision

用柔和路径串联停留节点，以植物高度和材质变化建立视觉节奏。

Value

展示从平面组织到户外氛围营造的综合景观设计能力。

Spatial Strategy

花园不只是“好看”，还要让人自然地停留、经过和使用。

PATH

柔性动线

通过弧形路径组织视线和行走节奏，让空间转换更自然。

PLANT

植物层次

用高低错落的植物形成边界、遮挡和季相变化。

REST

停留节点

将观赏、休憩和交流节点嵌入动线中，提升日常使用频率。
