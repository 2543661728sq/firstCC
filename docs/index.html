关于我

我是孙琪，浙江师范大学设计专业研究生，关注产品从概念、结构、CMF 到交互体验的完整表达。我擅长把用户场景、功能逻辑和造型语言整合成清晰、可落地的设计方案。

我的作品覆盖医疗康复设备、智能家庭硬件、婴幼儿产品、公共安全设施与景观空间设计。我希望用有温度的设计回应真实问题，让产品在可靠、易用之外，也能建立人与技术之间的信任感。
